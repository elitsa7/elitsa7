# 🚀 Featured Projects

## 💰 CrediHub

### Full-Stack Loan Management Platform

A full-stack digital loan management platform built with *Java 17, Spring Boot and Thymeleaf*, covering the complete loan lifecycle from application to repayment.
*Highlights:**

- 🔐 Authentication & role-based authorization

- 👥 User, Moderator and Administrator functionality

- 🧮 Loan calculator

- 📝 Loan applications and review

- 💰 Loan accounts and repayment schedules

- 💳 Stripe payments

- 🔗 OpenFeign communication with a dedicated microservice

- 🧪 Automated testing

- ☁️ Azure deployment

🔗 [**View CrediHub Repository**](https://github.com/elitsa7/credihub)  

🌍 [**Live Demo**](https://credihub-dhcmagcdhpb8dca7.uaenorth-01.azurewebsites.net/)

## 💳 CrediHub Payment Service

### Dedicated Payment Microservice

A standalone *Spring Boot microservice* responsible for the payment-related part of the CrediHub loan lifecycle.
*Highlights:**

- 🏦 Loan account management

- 📅 Repayment installment generation

- 💳 Payment processing and validation

- 🔄 Mock payment gateway for development and testing

- 💳 Stripe Checkout integration

- 🔔 Stripe webhook processing

- 📉 Loan balance updates

- ⏰ Scheduled overdue installment processing

- ⚡ Caching

- 🔐 API-key protected service communication

- 🧪 Automated testing

🔗 [**View Payment Service Repository**](https://github.com/elitsa7/credihub-payment-service)
